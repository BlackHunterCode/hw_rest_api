Tela Inicial

A API Finey oferece endpoints específicos para a tela inicial do aplicativo mobile.

Análise da Tela Inicial

Retorna dados de análise financeira para exibição na tela inicial do aplicativo.

POST /v1/screens-mobile/home/analysis

Corpo da Requisição

{
    "bankAccountIds": ["string"],
    "referenceDateMonthYear": "string",
    "startDate": "string",
    "endDate": "string"
}

Nome Tipo Obrigatório Descrição
Authorization String Sim Token JWT de autenticação (Bearer)
