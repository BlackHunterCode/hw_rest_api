Informações do Usuário

A API Finey permite obter informações sobre o usuário autenticado.

Obter Informações do Usuário

Retorna as informações do usuário autenticado com o token atual.

GET /v1/user/info

Cabeçalhos

Nome Tipo Obrigatório Descrição
Authorization String Sim Token JWT de autenticação (Bearer)

Resposta de Sucesso (200 OK)

{
    "status": "success",
    "statusCode": 200,
    "data": {
        "id": "string",
        "name": "string",
        "email": "string",
        "profilePicture": "string"
    }
}
