Análise Financeira

A API Finey oferece endpoints para análise financeira e projeções.

Projeção de Saldo Atual

Retorna a projeção do saldo atual com base nas transações e compromissos financeiros.

GET /v1/finance/analysis/current-balance-projection

Nome Tipo Obrigatório Descrição
Authorization String Sim Token JWT de autenticação (Bearer)
