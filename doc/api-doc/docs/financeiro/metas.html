Metas Financeiras

A API Finey permite criar e gerenciar metas financeiras para o usuário.

Criar Meta Financeira

Cria uma nova meta financeira para o usuário.

POST /v1/finance/goals/create

Corpo da Requisição

{
    "goalName": "string[ENCRYPTED]",
    "goalDescription": "string[ENCRYPTED]",
    "goalIcon": "💸[ENCRYPTED]",
    "goalColor": "string[ENCRYPTED]",
    "goalTargetAmount": "string[ENCRYPTED-Double]",
    "goalDate": "date"
}

Cabeçalhos

Nome Tipo Obrigatório Descrição
Authorization String Sim Token JWT de autenticação (Bearer)

Resposta de Sucesso (201 Created)

{
    "status": "success",
    "statusCode": 201,
    "data": {
        "goalId": "string",
        "goalName": "string[ENCRYPTED]",
        "goalDescription": "string[ENCRYPTED]",
        "goalIcon": "string[ENCRYPTED]",
        "goalColor": "string[ENCRYPTED]",
        "dGoalTargetAmount": "string[ENCRYPTED-Double]",
        "goalDate": 0
    }
}

Atualizar Meta Financeira

Atualiza uma meta financeira existente.

PUT /v1/finance/goals/update

Corpo da Requisição

{
    "goalId": "string-uuid"                                
    "goalName": "string[ENCRYPTED]",
    "goalDescription": "string[ENCRYPTED]",
    "goalIcon": "💸[ENCRYPTED]",
    "goalColor": "string[ENCRYPTED]",
    "goalTargetAmount": "string[ENCRYPTED-Double]",
    "goalDate": "date"
}

Cabeçalhos

Nome Tipo Obrigatório Descrição
Authorization String Sim Token JWT de autenticação (Bearer)

Resposta de Sucesso (200 OK)

{
    "status": "success",
    "statusCode": 200,
    "data": {
        "goalId": "string",
        "goalName": "string[ENCRYPTED]",
        "goalDescription": "string[ENCRYPTED]",
        "goalIcon": "string[ENCRYPTED]",
        "goalColor": "string[ENCRYPTED]",
        "dGoalTargetAmount": "string[ENCRYPTED-Double]",
        "goalDate": 0
    }
}
