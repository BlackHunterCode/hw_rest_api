Transações Financeiras

A API Finey permite gerenciar e consultar transações financeiras de diferentes contas bancárias.

Obter Total de Transações por Período

Retorna o total de transações em um determinado período para as contas bancárias especificadas.

POST /v1/finance/transactions/total-period Deprecated

Corpo da Requisição

{
    "bankAccountIds": ["string"],
    "referenceDateMonthYear": "string",
    "startDate": "string",
    "endDate": "string"
}

Parâmetros

Nome Tipo Obrigatório Descrição
bankAccountIds Array Sim Lista de IDs das contas bancárias
referenceDateMonthYear String Sim Data de referência no formato MM/YYYY
startDate String Sim Data inicial no formato ISO
endDate String Sim Data final no formato ISO

Resposta de Sucesso (200 OK)

{
    "status": "success",
    "statusCode": 200,
    "data": {
        "totalIncome": 0,
        "totalExpense": 0,
        "balance": 0
    }
}

Notas Importantes

O endpoint /v1/finance/transactions/total-period está marcado como obsoleto e será substituído em versões futuras.
