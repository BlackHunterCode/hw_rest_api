Compromissos Financeiros

A API Finey permite criar e gerenciar compromissos financeiros para o usuário.

Criar Compromisso Financeiro

Cria um novo compromisso financeiro para o usuário.

POST /v1/finance/financial-commitments/create

Corpo da Requisição

{
    "commitmentName": "string[ENCRYPTED]",
    "commitmentDescription": "string[ENCRYPTED]",
    "commitmentType": "string[ENCRYPTED]",
    "cronExpression": "string[ENCRYPTED]",
    "value": "string[ENCRYPTED-Double]",
    "startDate": "date",
    "endtDate": "date",
}

Cabeçalhos

Nome Tipo Obrigatório Descrição
Authorization String Sim Token JWT de autenticação (Bearer)

Resposta de Sucesso (201 Created)

{
    "status": "success",
    "statusCode": 201,
    "data": {
        "financialCommitmentId": "string-uuid",
        "commitmentName": "string[ENCRYPTED]",
        "commitmentDescription": "string[ENCRYPTED]",
        "commitmentType": "string[ENCRYPTED]",
        "cronExpression": "string[ENCRYPTED]",
        "value": "string[ENCRYPTED-Double]",
        "startDate": "string",
        "endDate": "string"
    }
}

Atualizar Compromisso Financeiro

Atualiza um compromisso financeiro existente.

PUT /v1/finance/financial-commitments/update

Corpo da Requisição

{
    "financialCommitmentId": "string-uuid"                                    
    "commitmentName": "string[ENCRYPTED]",
    "commitmentDescription": "string[ENCRYPTED]",
    "commitmentType": "string[ENCRYPTED]",
    "cronExpression": "string[ENCRYPTED]",
    "value": "string[ENCRYPTED-Double]",
    "startDate": "date",
    "endtDate": "date",
}

Cabeçalhos

Nome Tipo Obrigatório Descrição
Authorization String Sim Token JWT de autenticação (Bearer)

Resposta de Sucesso (200 OK)

{
    "status": "success",
    "statusCode": 200,
    "data": {
        "financialCommitmentId": "string-uuid",
        "commitmentName": "string[ENCRYPTED]",
        "commitmentDescription": "string[ENCRYPTED]",
        "commitmentType": "string[ENCRYPTED]",
        "cronExpression": "string[ENCRYPTED]",
        "value": "string[ENCRYPTED-Double]",
        "startDate": "string",
        "endDate": "string"
    }
}
